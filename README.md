# ShellLab >_

A safe, browser-based **CMD & PowerShell simulator** for learning Windows commands.
Nothing runs on your real computer, so you can experiment freely.

**Live demo:** https://yassen2012ya.github.io/shell-lab/

## Features
- **Two terminals:** Command Prompt and PowerShell, each with its authentic look and error messages
- **Fake commands that really "run":** `dir`, `cd`, `mkdir`, `net user`, `ping`, `ipconfig`, `sfc`, `DISM`, `chkdsk`, `bcdedit`, `bcdboot`, `bootrec`, `icacls`, `reg` and more
- **A fake file system:** create folders and files and watch `dir` update
- **Interactive DiskPart:** `list disk`, `select disk`, `clean`, `format`... in its own `DISKPART>` session
- **AI mode (✨):** type any command and get a detailed explanation: purpose, syntax, options, examples and warnings
- **Windows 11-style desktop** with a taskbar, window controls and live clock
- Arabic explanations, keyboard history (↑ ↓) and Tab completion
- A single HTML file with no dependencies, so it works offline

## Run it
Open `index.html` in any browser, or host it on GitHub Pages.
